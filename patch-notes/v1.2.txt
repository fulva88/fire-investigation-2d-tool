화재조사 2D 현장복원도 작성 도구 — 패치노트
버전: v1.2
날짜: 2026-08-19

============================================================
이번 패치 내용
============================================================

1. 나침반 회전 기능
   - 건물을 항상 정북 방향으로 그리게 되는 것은 아니기 때문에, 화면 보기 좋게
     자유롭게 그린 뒤 나침반만 실제 북쪽에 맞춰 돌릴 수 있게 했습니다.
   - 우측 상단 나침반 아이콘을 직접 마우스로 드래그해서 돌리거나, 오른쪽
     "표시 설정" 패널의 "북쪽 방향(°)" 입력란에 정확한 각도를 입력할 수
     있습니다. 도면에 그려진 벽/심볼 등은 전혀 움직이지 않고, 나침반
     표시만 바뀝니다. PNG/PDF 내보내기에도 그대로 반영됩니다.

2. 자동차 에셋 추가 (실제 축척)
   - "기타(부지/외부)" 프리셋에 기본형 승용차를 추가했습니다.
   - 전장 4.6m x 전폭 1.8m로, 배율 1일 때 실제 크기 그대로 도면에
     배치됩니다 (다른 심볼처럼 회전/크기 조절도 가능).

3. 선택 도구에서 좌클릭 드래그로 화면 이동
   - 지금까지는 화면을 옮기려면 마우스 가운데 버튼(휠 누르기)이나 스페이스바를
     눌러야 했는데, 이제 "선택/이동" 도구에서 빈 공간을 좌클릭 드래그하는
     것만으로도 화면을 이동할 수 있습니다. (휠 버튼 방식도 그대로 유지됩니다.)

4. 회전 조절 정밀 입력칸 추가
   - 심볼 속성 패널과 배경 이미지 패널의 "회전(°)" 게이지만으로는 미세 조절이
     어렵다는 의견을 반영해, 게이지 바로 아래에 정확한 각도 숫자를 직접 입력할
     수 있는 칸을 추가했습니다. 게이지를 움직이면 숫자도 같이 바뀌고, 숫자를
     입력해도 게이지가 같이 움직입니다.
