화재조사 2D 현장복원도 작성 도구 — 패치노트
버전: v1.0
날짜: 2026-08-14

============================================================
이번 패치 내용
============================================================

1. 벽난로 → 아궁이로 변경
   - "건축 요소" 팔레트의 벽난로 심볼을 전통 한옥/농촌가옥에서 흔히
     화재 발화지점으로 지목되는 "아궁이"(부뚜막 + 아치형 불 넣는 입구 +
     가마솥) 모양으로 다시 디자인했습니다.
   - 기존에 저장해둔 JSON 파일에 있던 벽난로 심볼도 그대로 아궁이
     모양으로 표시됩니다 (내부 ID는 유지).

2. 곡면 벽 그리기 (3점 아크)
   - 왼쪽 "도구" 패널에 "곡면 벽 (U)" 도구를 추가했습니다.
   - 사용법: ① 시작점 클릭 → ② 끝점 클릭 → ③ 곡선이 지나갈 지점을
     클릭하면 세 점을 지나는 원호(arc)가 벽으로 만들어집니다.
   - 스플라인 같은 복잡한 곡선 대신, 이해하기 쉬운 3점 아크 방식으로
     구현했습니다.
   - 곡면 벽은 두께 조절/전체 이동/삭제가 가능하며, 속성 패널에
     호 길이와 곡률 반지름이 표시됩니다. (모양을 다시 잡으려면 삭제
     후 다시 그려주세요 — 끝점 드래그 재편집은 지원하지 않습니다.)
   - PNG/PDF 내보내기에도 곡면 벽이 정확히 반영됩니다.

3. 기계설비 사각형 + 주석 편집 (공장화재 대비)
   - 왼쪽 "도구" 패널에 "기계설비 사각형 (M)" 도구를 추가했습니다.
   - 드래그로 사각형을 그리면 자동으로 "설비 1", "설비 2"... 식으로
     이름이 붙고, 오른쪽 속성 패널에서 이름(주석)을 자유롭게
     수정할 수 있습니다 (예: "프레스기", "보일러", "선반" 등).
   - 가로/세로 길이도 숫자로 정확히 입력할 수 있고, 모서리를 드래그해
     크기를 조절하거나 전체를 이동할 수도 있습니다.
   - 공장·작업장 화재조사 시 기계설비의 위치와 크기를 표시하는
     용도로 사용하세요.
